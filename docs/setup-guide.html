What it does

The PC reads AppFolio's Out for Signing leases every hour. The Google Sheet emails each tenant who hasn't signed yet, every few days, until the lease is signed, and sends your team a leasing summary each weekday morning. Each reminder also gets a ready-to-send text message in the sheet. Optional AI wording (Google Gemini) writes each reminder from the lease's real situation, in English or Spanish.

Before you start

☐A Google account for the emails, for example leasing@yourcompany.com. Everything is sent from it. (Free Gmail: about 100 emails a day; Google Workspace: about 1,500.)
☐An AppFolio login with access to reports and leasing. A dedicated user is best (see the limit below).
☐A Windows 10/11 PC that is on during business hours. Setup installs everything else.
☐Your password manager: you'll save a passphrase and a connection code in it.
☐Optional: a Gemini API key from aistudio.google.com/apikey, for AI wording.
AppFolio allows 500 report runs a day per login (it resets at midnight Eastern), shared by every PC signed in with that login. This install uses about 72 a day. If another tool or PC already uses the same AppFolio login, add up its runs first; past 500, every sync fails with run_limit_reached until midnight.
Never share your AppFolio password, MFA codes, the passphrase or the connection code by email or chat. You type them yourself, into the boxes setup opens.
A1

Create the sheet and paste the code

5 min
  1. Download Code.gs from the release page (next to this PDF) and open it in Notepad.
  2. Signed in as the email account, go to sheets.new. Name the sheet Lease Reminders.
  3. Extensions › Apps Script. A code editor opens in a new tab.
  4. Click in the editor, Ctrl+A, Delete. In Notepad: Ctrl+A, Ctrl+C. In the editor: Ctrl+V.
  5. Click Save (disk icon). Keep this tab open; you need it in A4.
A2

Set up the tabs

3 min
  1. Go back to the spreadsheet tab and reload it. After 5–10 seconds the AppFolio Tools menu appears.
  2. AppFolio Tools › 1. Set up this spreadsheet → Continue → pick the email account.
  3. Google says "Google hasn't verified this app". That's normal: it's your own script. Click Advanced → Go to … (unsafe) → Allow.
Check: the sheet now has the tabs Settings, Lease Tracker, Reminder Log, Bridge Log, plus Data: tabs.

A4

Deploy the web app (the PC's private address)

3 min
  1. In the Apps Script tab: Deploy › New deployment.
  2. Gear next to Select type → Web app.
  3. Execute as: Me. Who has access: Anyone.
  4. Deploy, approve if asked, and copy the Web app URL (it ends with /exec).
Why "Anyone"? The PC has no Google login, so the address must accept calls. Every call must carry the secret key from A5; calls without it are refused and logged in Bridge Log.
Check: opening the URL in a browser shows {"ok":true,"app":"AppFolio Assistant",…}.
A5

Get the connection code

1 min
  1. AppFolio Tools › 2. Connect the PC bridge.
  2. Paste the web app URL from A4 and click OK.
  3. Click Copy code and save it in your password manager. It starts with AFB1.
Check: you have a long code starting with AFB1. saved somewhere safe.
A6

AI wording (optional)

3 min
  1. Get a key at aistudio.google.com/apikey (it starts with AIza).
  2. AppFolio Tools › Save Gemini API key (AI wording) and paste it.
Without a key, or whenever Gemini is busy, reminders use the standard wording. If Gemini answers "prepayment credits are depleted", the key's Google project needs credit (or use a key from a project without billing).
Spanish: AppFolio doesn't record a tenant's language. Pick Spanish in the Lease Tracker's Language column and that tenant's email, subject and text switch to Spanish.
B

Install on the Windows PC

30 min

1. Python. Start menu › type PowerShell › open Windows PowerShell, and run:

PS> winget install -e --id Python.Python.3.12

Then close PowerShell and open a new one. python --version should say 3.12.

2. Download and set up: one command. Paste this into the new PowerShell window (it's one line):

$z="$env:TEMP\appfolio-leasing.zip"; Invoke-WebRequest https://github.com/JerryWest1/appfolio-leasing/releases/latest/download/appfolio-leasing.zip -OutFile $z; Expand-Archive $z C:\ -Force; cd C:\appfolio-leasing; Get-ChildItem -Recurse | Unblock-File; powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1

It downloads the latest version to C:\appfolio-leasing and starts setup, which asks:

B

If setup stops

Something went wrong? Fix it and run .\scripts\setup.ps1 again in C:\appfolio-leasing; finished steps are skipped.

If setup says…Do this
Python 3.11+ is requiredDo step 1, then open a new PowerShell window
…answered with a web page, not dataIn A4 set Who has access: Anyone and use the URL ending in /exec
That is not a connection codeCopy the whole code again from A5. It starts with AFB1.
The first sync failed (sign-in)Run .\scripts\refresh_appfolio_session.ps1, sign in again, then setup again
AppFolio's daily report limit is used up (run_limit_reached)Nothing is wrong with the PC. Another tool or PC on the same AppFolio login used the day's 500 report runs. Run setup again after midnight Eastern, and slow down whatever else uses that login
C

Test, then go live

10 min
  1. On the PC, in C:\appfolio-leasing:
    PS> .\scripts\run_job.ps1 -Job leasing -Test
    Check: your test address receives the leasing summary and one [TEST] email for each reminder that is due. The tracker's reminder counts don't change during a test.
  2. In the sheet: select a Lease Tracker row › AppFolio Tools › Email me a sample reminder for the selected row to see exactly what that tenant would get.
  3. AppFolio Tools › Preview reminders (no email) shows who would be emailed today, and why the others are skipped.
  4. Set any lease you don't want chased to Paused. Cancel or re-send stale leases in AppFolio.
  5. Go live: in Settings, clear Test mode email and set Send tenant reminders to YES.
  6. AppFolio Tools › Turn on automation. This starts the watchdog, which emails Alert emails if the PC goes quiet for more than a day.
Check: the next weekday at 9 AM, staff receive the Leasing summary, and the Reminder Log lists the reminders sent.

Text messages

Each reminder also writes a text in the Lease Tracker's Text to send column, with the number to text in Reminders go to. Copy it and send it from AppFolio or your phone.
